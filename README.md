# KeenKeeper

A smart and intuitive friendship management web application to track, organize, and analyze your social interactions.

## About the Project

KeenKeeper is a dedicated platform designed to help users maintain and nurture their personal relationships in an increasingly busy world. By allowing users to log communication details, view structured timelines, and analyze interaction frequencies, the application ensures that staying connected with friends becomes an organized and intentional habit.

## 🚀 Key Features

### 📞 Interaction Tracking
* Log daily communications including Phone Calls, Text Messages, and Video Chats.
* Categorize contact types to see how you interact most frequently.

### ⏱️ Activity Timeline
* View a clean, chronological history of all registered friend activities.
* Instantly check when you last reached out to a specific contact.

### 📊 Friendship Analytics
* Integrated data visualization powered by Recharts.
* Interactive charts that dynamically break down your social engagement patterns.

### 🔔 Real-Time Notifications
* Interactive alert banners integrated via React-Toastify.
* Instant visual feedback for successful logs, additions, and updates.
